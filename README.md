# Tick-Tick-Bloom
Harmful algal blooms occur all around the world, and can harm people, their pets, and marine life. Use satellite imagery to detect dangerous concentrations of cyanobacteria, and help protect public health!
Improved description:
This improvement is based on the code of the second place winner of this contest.Provides a more complete and complex machine learning process, including detailed feature engineering, data preprocessing, multiple model training, integration methods, performance evaluation, and visual presentation. Its integration method is more complex, providing both weighted integration and stacked integration.
